Three ways a site breaks

ปัญหาที่พบบ่อยในเว็บธุรกิจมีสามกลุ่ม แต่ละกลุ่มต้องแก้คนละวิธี

  • Bug Fix

    ปุ่ม ตัวกรอง หรือเมนูที่กดแล้วไม่ทำงาน ส่วนใหญ่เกิดจากโค้ดที่อ้างชื่อหรือค่าไม่ตรงกัน

  • Responsive Fix

    หน้าเว็บที่ล้นจอ ต้องเลื่อนซ้ายขวา หรือตัวหนังสือเล็กจนอ่านไม่ออกบนมือถือ

  • UI Improvement

    เว็บที่ใช้งานได้แต่ดูไม่น่าเชื่อถือ เพราะสี ตัวอักษร และระยะห่างไม่เป็นระบบ

Six fixes, explained

แต่ละจุดอธิบายว่าเกิดอะไร ทำไมถึงเกิด และแก้อย่างไร ส่วนโค้ดเปิดดูได้สำหรับคนที่อยากเห็นรายละเอียด

ตัวกรองคลาสทำให้รายการหายหมด

กลุ่มงาน Bug Fix

ปัญหาเดิม
กดตัวกรอง Yoga, Pilates หรือ Stretch แล้วตารางเรียนว่างเปล่า
สาเหตุ
ปุ่มส่งค่า “Yoga” แต่แต่ละแถวเก็บค่า “yoga” โค้ดเทียบแบบตรงตัวจึงไม่มีแถวไหนผ่าน
วิธีแก้
แปลงค่าทั้งสองฝั่งให้อยู่รูปแบบเดียวกันก่อนเทียบ และย้ายสถานะ “เลือกอยู่” ไปที่ปุ่มที่กด
ผลลัพธ์
แสดงเฉพาะคลาสที่เลือก พร้อมบอกจำนวนคลาสที่พบ
ดูโค้ดที่แก้ไข

ปุ่มเมนูบนมือถือไม่ตอบสนอง

กลุ่มงาน Bug Fix

ปัญหาเดิม
บนมือถือ กดปุ่มเมนูแล้วไม่มีอะไรเกิดขึ้น ผู้ใช้ไปหน้าอื่นไม่ได้
สาเหตุ
สคริปต์เพิ่มคลาส active แต่ CSS รอคลาส show และปุ่มเป็น div ที่คีย์บอร์ดเข้าถึงไม่ได้
วิธีแก้
เปลี่ยนเป็นปุ่ม button ที่บอกสถานะเปิดปิด ใช้ชื่อสถานะเดียวกันทั้ง JS และ CSS
ผลลัพธ์
เมนูเปิดปิดได้ทั้งนิ้ว เมาส์ และคีย์บอร์ด กด Esc เพื่อปิดได้
ดูโค้ดที่แก้ไข

ปุ่มหลักบนหน้าแรกกดไม่ติด

กลุ่มงาน Bug Fix

ปัญหาเดิม
ปุ่ม “ดูตารางคลาส” มองเห็นได้ แต่ใช้เมาส์หรือนิ้วกดแล้วไม่ไปไหน
สาเหตุ
ชั้นลายตกแต่งโปร่งใสวางทับทั้งส่วนหัวเว็บ การคลิกจึงไปโดนชั้นนั้นแทนปุ่ม
วิธีแก้
ทำลายตกแต่งเป็นพื้นหลังที่ไม่รับการคลิก และจัดลำดับชั้นของปุ่มใหม่
ผลลัพธ์
ปุ่มหลักกดได้ทุกอุปกรณ์ และพาไปที่ตารางเรียนทันที
ดูโค้ดที่แก้ไข

หน้าเว็บล้นจอบนมือถือ

กลุ่มงาน Responsive Fix

ปัญหาเดิม
บนมือถือต้องเลื่อนซ้ายขวาเพื่ออ่าน และการ์ดคลาสใบที่สามตกไปอยู่บรรทัดใหม่แม้บนจอคอม
สาเหตุ
กล่องเนื้อหาและตารางกำหนดความกว้างตายตัว 1100 px และ 1060 px ส่วนการ์ดคิดความกว้างไม่รวมขอบ
วิธีแก้
ใช้ความกว้างสูงสุดแทนความกว้างตายตัว จัดการ์ดด้วย CSS Grid และเปลี่ยนตารางเป็นรายการบนจอเล็ก
ผลลัพธ์
เนื้อหาพอดีทุกขนาดจอ ตั้งแต่มือถือ 375 px ถึงจอคอม
ดูโค้ดที่แก้ไข

ตัวหนังสือและปุ่มเล็กเกินไป

กลุ่มงาน Responsive Fix

ปัญหาเดิม
ตัวหนังสือบนมือถืออ่านยาก ปุ่มตัวกรองและลิงก์เมนูเล็กจนกดพลาดง่าย
สาเหตุ
เนื้อหาใช้ตัวอักษร 13 px ปุ่มตัวกรอง 11 px และพื้นที่กดสูงไม่ถึง 30 px
วิธีแก้
ตั้งขนาดตัวอักษรขั้นต่ำ 16 px และให้ทุกปุ่มสูงอย่างน้อย 44 px
ผลลัพธ์
อ่านได้โดยไม่ต้องซูม และกดถูกปุ่มตั้งแต่ครั้งแรก
ดูโค้ดที่แก้ไข

สีและระยะห่างไม่เป็นระบบ

กลุ่มงาน UI Improvement

ปัญหาเดิม
หัวข้อสำคัญไม่เด่น ปุ่มมีสามแบบ ราคาเขียนสามรูปแบบ และข้อความสีเทาอ่อนอ่านยาก
สาเหตุ
แต่ละส่วนกำหนดสี ฟอนต์ และระยะห่างแยกกันเอง โดยไม่มีระบบกลาง
วิธีแก้
สร้างชุดค่ากลาง (design tokens) สำหรับสี ตัวอักษร และระยะห่าง แล้วใช้ร่วมกันทั้งหน้า
ผลลัพธ์
ทั้งเว็บดูเป็นชุดเดียวกัน และสีตัวอักษรตัดกับพื้นตามเกณฑ์ WCAG AA
ดูโค้ดที่แก้ไข

Three packages, priced by scope

ราคาเริ่มต้นตามแพ็กเกจบน Fastwork ราคาสุดท้ายขึ้นอยู่กับขอบเขตงานและสภาพโค้ดเดิม และจะแจ้งก่อนเริ่มงานเสมอ

แพ็กเกจ เหมาะกับ สิ่งที่ทำให้ ราคาเริ่มต้น
Bug Fix ปุ่ม ฟอร์ม เมนู หรือสคริปต์ที่ทำงานผิดพลาด หาสาเหตุ แก้เฉพาะจุด ทดสอบซ้ำ และสรุปสิ่งที่แก้ ฿800
Responsive Fix เว็บที่แสดงผลเพี้ยนหรือล้นจอบนมือถือและแท็บเล็ต ปรับเลย์เอาต์ ตัวอักษร และปุ่มให้ใช้ได้บนมือถือ แท็บเล็ต และจอคอม ฿1,500
UI Improvement เว็บที่ใช้งานได้แต่ดูเก่า อ่านยาก หรือไม่เป็นชุดเดียวกัน จัดระบบสี ตัวอักษร ระยะห่าง และปุ่ม โดยคงเนื้อหาเดิมไว้ ฿2,500

From inspection to handover

  1. Inspect

    ตรวจเว็บไซต์เดิมบนหลายขนาดจอ และอ่านโค้ดส่วนที่เกี่ยวข้อง

  2. Reproduce

    ระบุปัญหาและทำให้เกิดซ้ำได้ เพื่อยืนยันสาเหตุก่อนแก้

  3. Fix

    แก้ตรงจุดที่เป็นสาเหตุ ไม่รื้อส่วนที่ทำงานดีอยู่แล้ว

  4. Test

    ทดสอบซ้ำบนอุปกรณ์และเบราว์เซอร์ที่เกี่ยวข้อง

  5. Deliver

    ส่งโค้ดที่แก้แล้ว พร้อมสรุปรายการที่เปลี่ยน
